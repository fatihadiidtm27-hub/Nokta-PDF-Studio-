# NOKTA // PDF STUDIO

Bagian dari **NOKTA Creator Suite**. Susun e-book, lead magnet, atau panduan digital blok demi blok langsung di browser, lalu ekspor jadi PDF.

## Fitur
- Sampul dengan judul, subjudul, penulis, gambar sampul opsional
- Blok isi: Judul Bagian, Paragraf, Gambar, List, Kutipan, Halaman Baru
- 3 tema dokumen: NOKTAWave (modern), Editorial Warm (serif hangat), Minimal Mono
- Edit langsung di pratinjau (WYSIWYG), atur urutan blok dengan ⬆⬇, hapus dengan ✕
- Ekspor lewat fitur "Print → Save as PDF" bawaan browser — tanpa library tambahan, hasil PDF asli
- Kode akses **sama dengan tools NOKTA lain** — satu lisensi buka semua tools NOKTA

## Cara ekspor ke PDF
1. Susun dokumen sampai selesai
2. Ketuk tombol **⬇ PDF** di pojok kanan atas
3. Di dialog print yang muncul, pilih printer **"Save as PDF"** (Android/Chrome sudah punya opsi ini bawaan)
4. Simpan

## Deploy ke GitHub Pages
```bash
git init
git add .
git commit -m "Initial commit: NOKTA PDF Studio"
git branch -M main
git remote add origin https://github.com/<username>/<nama-repo>.git
git push -u origin main
```
Lalu **Settings → Pages** → Source: branch `main`, folder `/ (root)` → Save.
